# Space Parking Lot
## Parking lot register for Spaceships

This project demonstrates the use of Python's POO Fundamentals, just as the basics like functions, conditionals, and exceptions cases.

### Overview
This program allows you to register your spaceship, its name and model, based on a pre-existing dictionary of spaceship models, and if there's no dictionary, the program uses the default one.

e.g: 
| Model | Price |
| :--- | :--- |
| `X-Wing` | 15.00 | -> Spaceship model | Spaceship price per hour parked at the station

### V1
This project started as a trial to create a program based on the **CS50P** course **Introduction to Programming with Python**, made after I learned about **EAFP/LBYL** on try/except cases.
The 1st version has a pre-existing dictionary with the ship model and its price, and functions to use as the menu on the main function, with some hard conditional structure of if/else and exceptions.
